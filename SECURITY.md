# Segurança

## Versões com suporte

Só a versão mais recente publicada em **Releases** recebe correções.

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use **Security → Report a vulnerability** neste repositório, que é o relato privado do GitHub, ou fale diretamente com a pessoa responsável pelo projeto. Informe:

- o que é possível fazer;
- os passos para reproduzir;
- a versão do app afetada.

## Dados

O app guarda os dados apenas no aparelho e não envia nada pela internet. Os backups exportados contêm os dados do projeto (equipes, tarefas e evidências) e devem ficar em um local de armazenamento institucional.
